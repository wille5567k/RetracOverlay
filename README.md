# RetracOverlay

[Ladda ner RetracOverlay.exe för Windows x64](https://github.com/wille5567k/RetracOverlay/releases/latest/download/RetracOverlay.exe)

1. Dubbelklicka på `RetracOverlay.exe`. .NET ingår i filen.
2. Tryck **F8** för att dölja menyn. Tryck **F8** igen för att visa den.
3. Stäng fönstret med **X** när du vill avsluta.

Om du provar menyn bredvid spelet, välj kantlöst fönsterläge (Borderless Windowed) om det finns. RetracOverlay är en fristående menyprototyp. Reglagen är förhandsvisningar. Det finns ingen speldataanslutning, live-ESP, aimbot eller anti-cheat-bypass.

## Bygg från källkod

Med .NET 8 SDK installerat kan du köra `build.bat`. EXE-filen hamnar i `bin\Release\net8.0-windows\win-x64\publish`. GitHub Actions bygger på Windows och publicerar första versionen som `v1.0.0` från `main`. Skicka upp en ny versionstagg, till exempel `v1.0.1`, för att publicera nästa version.
