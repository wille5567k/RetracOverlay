# Retrac Overlay

Windows Forms external overlay prototype for testing an F8 show/hide menu.

## Build

Install the .NET 8 SDK, then run `build.bat`.

Output: `bin\Release\net8.0-windows\win-x64\publish\RetracOverlay.exe`.

Run Retrac in Borderless Windowed mode, then launch the EXE. Press F8 to show/hide the menu.

**Note:** This is an interface prototype, not an online ESP, aimbot, anti-cheat bypass or live player tracker. Windows/game compatibility has not been verified.
